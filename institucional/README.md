# Pipou — site institucional

Site estático responsivo, sem dependências de instalação. HTML, CSS e JavaScript em `dist/`.

## Desenvolvimento

Execute `npm run dev` e abra http://127.0.0.1:4173. `npm run check` verifica a sintaxe do JavaScript.

## Publicação no Netlify

Use esta pasta como diretório base e `dist` como diretório de publicação. Não é necessário comando de build. A configuração está em `netlify.toml`.
